# Fotos de teste do bordado

Coloque aqui **somente fotos que você tem autorização para usar** (jpg, png ou webp). Esta pasta não vai para o git.

```
npm run gallery        # gera dist-gallery/
npm run gallery:serve  # abre http://localhost:4180/gallery.html
```

A galeria mostra a foto original e o resultado de cada método (A, B, C, D, E e o clássico) com tempo e porcentagem de tinta.
